Goal:

Add a pure deterministic pattern-source series intake registry for agent routing — not player-facing canon. Tracks multi-entry source clusters (series hubs) separately from single articles, location/event logs, canons, or organization indexes while preserving only Containment Protocol-safe implementation patterns.

Scope:

- `PatternSourceSeriesId` + `PatternSourceSeriesRecord` in `src/domain/patternSourceSeriesRegistry.ts` — **sourceFamily** (`series_hub`, `canon_hub`, `single_article`, `organization_format`, `location_log`, `event_log`, `item_log`, `tale`, `anthology`, `meta_hub`), **publicationOrder** (external pub date only), **editorialStatus** (`featured`, `spotlight`, `open_entry`, `completed`, `active`, `abandoned`, `high_signal`, `low_confidence`), **dedicatedTag**, **processingStatus** (`unqueued`, `blurb_triaged`, `deep_pass`, `reconciled`, `deferred`, `rejected`), **readinessScore**, **blurbDomainHints\[\]**, slug/title/description stubs (CP-neutral internal labels only), **linkedClusterIds\[\]**
- add compact adaptation metadata for source-normalization state, expression-risk flags, and normalization notes where a source depends on distinctive prose, source-specific naming, plot sequence, character identity, branded labels, named organizations, or problematic framing that cannot be safely copied into CP
- `validatePatternSourceSeriesRecord(record)` — branded label token → error; `canon_hub` on series archive intake → warning; blurb-only `deep_pass` without `blurb_triaged` → warning; publication date used as implementation priority → warning; protected/source-specific expression without normalization handling → warning; imported plot, setting, character identity, or organization name in CP-neutral fields → error
- `projectSeriesProcessingQueue(records, policy)` — rank by readinessScore + CP utility, not recency
- `classifyBlurbDomains(blurbStub)` — facility / faction / disclosure / object / media / personnel / ecology / disaster / occult / ethics (routing hints only)
- Tests in `src/test/patternSourceSeriesRegistry.test.ts`

Constraints:

- Deterministic only; no GameState persistence in slice 1.
- External archive metadata must not become in-world evidence.
- Series ≠ canon continuity; blurbs are triage not proof.
- Open-entry and anthology modes carry confidence limits.
- No franchise names, wiki URLs, imported series titles, protected prose, plot sequences, character identities, or branded organizations in records.
- Source material must be translated into CP-safe operational terms before treated as implementation-ready.
- Harmful source framing may be preserved only as normalized risk patterns (institutional bias, witness unreliability, authority abuse, community harm, exposure risk, coercion, misinformation).

Acceptance criteria:

- Fixture: series_hub record with open_entry + completed flags coexisting as editorial metadata.
- Queue projection prefers high readiness over recent publicationOrder.
- Negative: imported organization name in title field → validation error.
- Negative: distinctive expression or source-specific character identity in a CP-neutral record field → validation error.
- Fixture: source record with expression-risk flags remains pattern-library/provisional until a normalization note exists.
- Cross-cluster reinforcement ref without duplicate issue creation (hook field only).

Deferred:

- planning mirror dashboard UI
- automated article-level queue generation
- wire-up to Linear MCP workflow

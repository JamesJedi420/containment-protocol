## Scope

Covers carried artifacts and specialized tools whose runtime behavior depends on switchable modes, taboo charging, bounded output states, and authorable activation tradeoffs.

## Mode-switched artifacts

- A single carried anomaly may expose several distinct active modes under one possession or command state.
- Mode suites can include restraint, scanner, weapon, light, recorder, probe, barrier, or similar roles when training, timing, and failure rules permit.
- These are not simple charged items repeating one verb.
- Tactical and social behavior may change because the object is held, recognized, or switched into a different mode.

## Biomaterial-charged escalation

- Some artifacts maintain a baseline mode plus a stronger temporary mode unlocked only through taboo biological charging material.
- Charging windows should be short, explicit, and timing-sensitive.
- Biomaterial charging is distinct from ordinary charges, mana budgets, or generic blood-magic assumptions.
- Higher modes should not be morally neutral or infinitely reusable by default.

## Multi-mode illumination tools

- A single tool may switch among beam, cone, flash, ignition, reveal, or comparable illumination states.
- Utility and combat-adjacent outputs should remain distinct in authored state, not just in flavor text.
- One reusable mode grammar should support all included light outputs.

## Distinctions to preserve

- One artifact does not imply one verb.
- Charged escalation is distinct from ordinary charge consumption.
- Illumination state is not a cosmetic toggle when it changes reveal, ignition, or tactical output.

## Non-goals

- No universal omni-artifact sandbox.
- No universal blood-magic sandbox for all items.
- No broad gadget simulator.

## Expected use

Use this doc when designing carried anomalies or field tools that need explicit runtime mode states, taboo charging behavior, or bounded output suites that materially affect play.

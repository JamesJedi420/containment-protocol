# Background Packages and Inherited Start State (SPE-83)

## Purpose

Start state is assembled from **reusable background packages** with **separable layers** — not a single biography paragraph. This enables fast-stock actors, roguelike seeds, and deterministic audits without a full life-path simulator.

## Layered composition

- **Culture** — language, taboo tags, default naming module weights (`architecture/procedural-naming-layered-identity.md`).
- **Origin** — geography, class background, crisis-adjacent hooks.
- **Role** — agency-facing slot, clearance, and initial competency bands.

Packages **compose**; collisions resolve with explicit precedence rules.

## Package contents (bounded)

Backgrounds may grant:

- **Resources and access** — contacts, licenses, smuggler paths.
- **Liabilities** — enemies, debts, exile pressure, captivity history.
- **Career events** — short deterministic event chains that stamp tags.
- **Inherited hooks** — clues, obligations, or evidence items carried into week 1.
- **Occupational gear** — role-legal kit without bypassing certification gates improperly.

## Fast-stock intake

Use the **same grammar** for procedurally generated operatives as for authored backgrounds so validation stays unified.

## Anti-patterns

- “Flavor-only” backgrounds that do not touch canonical state.
- Unlimited freeform backstory fields without gameplay tags.

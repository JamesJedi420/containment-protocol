# Overlapping Holdings and Layered Territory Control (SPE-170)

## Purpose

One region can carry **overlapping holding layers** — civic, temple, guild, anomaly-source, kinship, scout webs, etc. — each with different owners and interaction rules. Territory is **not** a flat sovereign flag.

## Holding layers

Examples:

- **Civic control** — municipal or state authority.
- **Temple / doctrine control** — religious or ideological presence.
- **Guild / economic control** — trade, labor, black markets.
- **Anomaly-source control** — who holds or exploits anomalies.
- **Kinship / clan control** — lineage-based influence.
- **Scout / informant webs** — information control layer.

Each layer has:

- an owner set,
- strength or weight,
- interaction rules.

## Weighted control and tie-breaks

Control for a given question (tax, detention, salvage) comes from **weighted combinations** across layers with deterministic tie-break logic (policy).

## Layer-specific actions

Actions can:

- suppress a single layer,
- bargain with one layer to gain or trade control,
- or selectively boost one without replacing the rest.

## Integration

- **Governance** (SPE-168) — strategic turns adjust layer weights.
- **Legitimacy** — faction docs should reference layered holdings instead of single allegiance.

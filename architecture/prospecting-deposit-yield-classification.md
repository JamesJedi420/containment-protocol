# Prospecting, Deposit Yield, and Worked Value (SPE-143)

## Purpose

**Prospecting** returns **deposit class**, **yield / quality**, and **confidence** — not a binary find/empty. **Confident misclassification** is a supported failure mode.

## Discovery record shape

- **Class** — ore type, biological matrix, occult sediment, etc.
- **Yield band** — expected tonnage or potency range.
- **Confidence** — how sure the survey is; high confidence can still be **wrong** if bias or sabotage exists.

## Surface proof methods

Panning, shallow pits, drone grids, or ritual dowsing each shift confidence and cost curves differently.

## Conversion to worked value

Deterministic pipelines convert **raw deposit** → **refined / traded** value with losses, spoilage, or ritual attrition at each step.

## Integration

- **Economy / procurement** — feeds funding and market availability (`docs/funding-procurement-budget-pressure-audit.md`).
- **SPE-85** — outsourced surveys may carry hidden quality bands.

# Territorial Power Nodes and Domain Casting Economy (SPE-167)

## Purpose

Region-scale capability depends on explicit **power nodes**, **conduit links**, **yields**, **suppression states**, and **authority-backed expenditure** — not vague “regional magic” or caster reach alone.

## Node network

- **Nodes** — shrines, reactors, anchors, turbines, rift-wells.
- **Conduit links** — paths where power or influence flows (rivers, ley lines, fiber, ritual chains).
- **Yields** — how much usable power or effect budget the network produces per tick.
- **Suppression states** — dead terrain, corrupted nodes, interdicted lines.

## Authority-backed expenditure

Large-scale effects require:

- explicit authorization,
- cost bookkeeping (power, materials, legitimacy),
- and sometimes multi-org consent (city + temple + sponsor).

## Territorial mechanics

Examples:

- **Dead-terrain suppression** — no large-scale effects possible; only local tricks.
- **Open-terrain power lines** — reinforce or destabilize borders and fortifications.
- **Outsider-only navigation wards** — routes that only work for tagged actors.
- **Strategic isolation barriers** — bounded exclusion zones with explicit failure modes.

## Integration

- **World-law profiles (SPE-151)** — domains define which node families they support.
- **Maritime and submerged sites** — sea-floor nodes and vents extend networks underwater.

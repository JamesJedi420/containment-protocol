# Agency establishment presentation (SPE-2907)

`AgencyEstablishmentPanel` in `src/features/agencyEstablishment` is a consumable single-flow briefing surface. Entry owners may mount it explicitly and supply current `accessibility`, `resolveBinding`, and optional `onComplete` props. It does not modify application routes or automatically run on New Campaign/Continue/Load. SPE-2908 owns entry and Week-1 handoff integration.

`AGENCY_ESTABLISHMENT_TUTORIAL` registers one sequenced version-1 definition with the seven canonical `AGENCY_ESTABLISHMENT_BEAT_IDS`. Its lifecycle is persisted through the existing tutorial runtime. Begin, advance/complete, back, skip, pause/resume, suppression restoration and replay use ordinary commands; no component-local step state or new store exists. Remaining-flow skip composes canonical step skips; fully skipped flows remain skipped, while mixed reviewed/skipped flows retain the runtime's completed status with skipped steps preserved.

`projectAgencyEstablishmentView` only labels/formats `buildAgencyEstablishmentProjection(game)`. It never reads extra case payloads or recomputes triage, routing, intel, logistics, readiness, ledger or campaign values. Optional support/maintenance capacity displays unavailable when absent; a null dossier remains an ordinary unavailable state and never blocks advance. Command identity comes from the projection; anonymous identity retains the canonical managerial/team-first framing. Routing summaries, factors, details/severity and intel confidence/uncertainty remain visible text rather than hover/color-only meaning.

`dispatchAgencyEstablishment` and `skipAgencyEstablishment` bind to the merged application tutorial runtime. `agencyEstablishmentHandoff` forwards a new generic completion or flow-skip event for this exact tutorial/version as `{ token: 'review-the-week', tutorialId, definitionVersion, run, revision, outcome }`. The token comes from the projection's activation payload. Stale dispatches produce no signal; terminal mount, suppression restoration, replay start and unrelated tutorial completion cannot emit it. Consumers should forward only the newly returned command result, rather than replaying a previously consumed transient result. Persisted terminal state remains available through the ordinary archive after reload.

Active progress survives unmount/save-load without restarting; Pause records explicit interruption. Replay rebuilds current projection content and changes only guidance/debug state, never campaign initialization, rewards, resources or production actions. Parent SPE-2903 remains open for entry/handoff and integrated regression slices.

Accessibility uses the SPE-2919 normalization helper and semantic content. Current navigation labels resolve through the injected binding interface using semantic `tutorial.*` action IDs; missing mappings retain ordinary labeled buttons. No key, device profile, global action registry, remapping engine or preference store is added. The panel focuses the current heading, exposes progress/current-step semantics, and uses static presentation in both motion modes. Reduced-motion styling removes local transitions; text scale applies to paragraphs, facts, headings and buttons with responsive wrapping. Controller/pointer/touch consumers use the same labeled controls through ordinary activation; global device handling belongs to SPE-3395.

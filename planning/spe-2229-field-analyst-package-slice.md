# SPE-2229 — field analyst authoring package

[SPE-2229](https://linear.app/spectranoir/issue/SPE-2229/occult-field-analyst-staff-role-package-slice-1) defines an authoring template under SPE-1639, not a live staff member. Competency keys match the existing competency domains; signature trait identifiers must match existing CP trait definitions. This allowlist rejects unrecognized source-specific names but is not a general copyright classifier.

Document access is an opaque reference checked against the caller's known policy references. A valid reference does not grant clearance. No imported source statistics, persisted staff, progression, or gameplay consumer is introduced. The existing staff-role test file covers fixture validation, rejected unknown keys and non-CP trait names, known access, deterministic lookup, and duplicate IDs.

## Contracts and integration

- `src/app/referenceLibrary.ts`: at most 256 entries / 16 categories, bounded authored strings and query, stable exact-ID lookup, category order then code-unit ID order. Configured Unicode, case, apostrophe/backtick, dash and optional diacritic transforms affect lookup only. Explicit aliases cover non-mechanical spelling variants. Colliding normalized labels retain distinct IDs; duplicate stable IDs are quarantined. Withheld entries never enter search/direct/related lookup; missing/self/duplicate related links are omitted.
- `src/app/referenceLibraryView.ts`: public catalogue labels from ROLE_LABELS and ROLE_COVERAGE_LABELS/TEAM_COVERAGE_ROLES, navigation limit from NAVIGATION_HISTORY_LIMIT, actual controls labels from the canonical binding resolver. Unknown producers fail visibly. The adapters accept no GameState or private-entity input. No campaign-specific mechanics, hidden capabilities, confidence upgrade or fabricated rules. The information entry is explicitly explanatory guidance, not an operational assessment. No operational reason/provenance adapter is needed for these universally public catalogue/configuration fields.
- `ReferenceLibrary` is reused by `/help` and `ReferenceAccess`. Header Help opens a native modal without route changes; Agents' Specialization reference targets a stable entry through `dispatchInputAction('reference.open', id)`. Contextual/tutorial consumers may use that same API; no tutorial lifecycle changes. Related entries reuse one selected ID, not a second router/history stack. Return to results preserves query/category and restores the matching result or search focus; native dialog dismissal restores the invoker.
- Canonical input adds `reference.open`, `reference.previous`, `reference.next`; `modal.dismiss` keeps its ID and now has the generic display label Dismiss dialog. Existing saved overrides win against newly introduced defaults; conflicting explicit overrides still fail normalization, and live capture still rejects collisions. Controller modal dismiss/reference traversal remains available while search has focus; keyboard editing/IME and background commands remain protected.
- The initial five entries cover controls, navigation, public specialization/coverage labels and information-reading guidance. Structured IDs/text support later localization without implementing a localization subsystem. Pins/read persistence has no demonstrated material benefit for this small catalogue and is omitted. Query/category/selection are session UI state only; no derived indexes or simulation truth enter campaign storage.

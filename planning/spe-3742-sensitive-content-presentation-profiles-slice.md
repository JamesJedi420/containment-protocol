# SPE-3742 Sensitive-content presentation profiles (slice)

Bounded domain projection only. Profiles map the same canonical bodily state to explicit, clinical, or symbolic cues while preserving mechanical severity, operational facts, and mandatory warnings. Malformed profile falls closed to clinical. No UI, settings persistence, or simulation mutation in this slice.

Acceptance covered:
- Same state projected through two+ profiles with identical mechanical severity.
- Reduced-graphic equivalent preserves actionable operational fact and critical warning.
- Fail-closed on unknown profile.
- No state mutation.

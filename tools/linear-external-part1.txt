## Purpose

This document collects the out-of-boundary documentation updates identified during the issue pass starting after <issue id="e6d2c25b-fc24-4858-a08e-54d7e9603e8d">SPE-185</issue>. These are prompts for docs that are not currently editable inside the Containment Protocol project-document boundary.

## Follow-up prompts
